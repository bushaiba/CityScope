About / The idea

Clearer data, better decisions.

CityScope is a small web app using public data. It turns public API responses into accessible information without requiring registration or payment.

Location data: Open-Meteo Geocoding.

Weather source: Open-Meteo Forecast API.

Additional sources: Open-Meteo Air Quality and Sunrise-Sunset.org.
